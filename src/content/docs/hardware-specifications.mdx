## Detailed Node Profiles 🖥️

### Node 1 (Large): `com` (HP ProDesk Mini G2)
* **IP Address**: `192.168.1.210:8006`[cite: 1]
* **Processor**: Intel Core i5-7400 (4 Cores / 4 Threads @ 3.00 GHz Base / 3.50 GHz Boost)[cite: 1]
* **iGPU / Transcoding**: Intel HD Graphics 630 (HEVC 10-bit QuickSync)[cite: 1]
* **Memory**: 32 GB DDR4[cite: 1]
* **Internal Storage**: 1 TB System SSD[cite: 1]
  * `local`: Directory (`/var/lib/vz`) for ISOs, CT templates, and backups[cite: 1].
  * `local-lvm`: LVM-Thin Pool for VM/LXC block storage[cite: 1].
* **External Direct-Attached Storage (DAS)**: 5-Bay USB 3.2 Gen 2 SATA Enclosure[cite: 1]
  * `/mnt/sdb1`: ~3.64 TB[cite: 1]
  * `/mnt/sdc1`: Unassigned / Reserved[cite: 1]
  * `/mnt/sdd1`: ~3.64 TB[cite: 1]
  * `/mnt/sde1`: ~3.64 TB[cite: 1]
  * `/mnt/sde2`: ~5.46 TB[cite: 1]
  * `/mnt/sdf1`: ~5.46 TB[cite: 1]

### Node 2 (Small): `dell` (Dell OptiPlex Micro)
* **IP Address**: `192.168.1.220:8006`[cite: 1]
* **Processor**: Intel Core i3-4160 (2 Cores / 4 Threads @ 3.10 GHz)[cite: 1]
* **iGPU / Transcoding**: Intel HD Graphics 4400[cite: 1]
* **Memory**: 16 GB DDR3 (15.54 GiB total host recognized)[cite: 1]
* **Boot Mode**: Legacy BIOS[cite: 1]
* **Internal Storage**: 512 GB System SSD[cite: 1]
  * `local`: Directory (`/var/lib/vz`, 93.93 GiB root partition)[cite: 1].
  * `local-lvm`: LVM-Thin Pool (413.54 GiB capacity)[cite: 1].

### Node 3 (Medium): `lenovo` (Lenovo ThinkCentre Tiny)
* **IP Address**: `192.168.1.230:8006`[cite: 1]
* **Processor**: Intel Core i3-7100T (2 Cores / 4 Threads @ 3.40 GHz)[cite: 1]

  * `local`: Directory (`/var/lib/vz`, 67.73 GiB root partition)[cite: 1].
  * `local-lvm`: LVM-Thin Pool[cite: 1].

## Architectural & Compatibility Notes ⚙️

:::caution[CPU Heterogeneity & Live Migration]
Because **Node 2 (`dell`)** uses 4th Gen Haswell architecture while **Nodes 1 & 3 (`com` & `lenovo`)** use 7th Gen Kaby Lake, passing raw `host` CPU types to guest VMs will break live migration. 

To enable seamless live migration across all nodes, all guest VMs must be configured to use the custom CPU model **`x86-64-v2-AES`**[cite: 1, 2].
:::
